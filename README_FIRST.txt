NEXUS HARDWARE QUALIFICATION
==============================

1. Open/run NEXUS_Qualification.
   - Windows: double-click NEXUS_Qualification.bat
   - macOS:   double-click NEXUS_Qualification.command
   - Linux:   run ./NEXUS_Qualification.sh
2. Connect the laptop charger if the application asks.
3. Do not close the application while the test is running
   (about 10 minutes, plus setup).
4. Wait for the final report (it opens automatically).
5. Send the generated NEXUS_Qualification_....zip file to the buyer.

No files need to be selected.
No benchmark settings need to be changed.
No Python, model, video, or dataset setup is required:
the official test package is included and verified automatically.
